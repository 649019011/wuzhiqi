# 五子棋游戏

一个现代化的网页五子棋游戏，支持双人对战和人机对战。

## 功能特性

- 🎮 **双人对战模式**：两个玩家轮流下棋
- 🤖 **人机对战模式**：与智能AI对战
- 📱 **响应式设计**：完全适配手机和平板设备
- 🎯 **智能AI**：具备进攻和防守策略
- 🏆 **获胜检测**：自动检测五子连线
- 🔄 **重新开始**：一键重置游戏

## 游戏规则

1. 黑棋先行，玩家轮流下棋
2. 在15×15的棋盘上，先连成五子的一方获胜
3. 可以横向、纵向或对角线连线
4. 支持双人对战和人机对战

## 技术栈

- HTML5
- CSS3 (响应式设计)
- JavaScript (ES6+)
- 无需外部依赖

## 部署

### 本地运行
直接在浏览器中打开 `gomoku.html` 文件即可开始游戏。

### Vercel部署
1. 将代码推送到GitHub仓库
2. 在Vercel中导入GitHub仓库
3. 自动部署完成
