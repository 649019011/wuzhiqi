# 网页游戏合集

包含两个有趣的网页游戏，支持桌面端和移动端。

## 🎮 游戏列表

### 1. 五子棋游戏 (`gomoku.html`)

一个现代化的网页五子棋游戏，支持双人对战和人机对战。

#### 功能特性
- 🎮 **双人对战模式**：两个玩家轮流下棋
- 🤖 **人机对战模式**：与智能AI对战
- 🎯 **四个难度等级**：简单、中等、困难、专家
- 📱 **响应式设计**：完全适配手机和平板设备
- 🏆 **获胜检测**：自动检测五子连线
- 🔄 **重新开始**：一键重置游戏

#### 游戏规则
1. 黑棋先行，玩家轮流下棋
2. 在15×15的棋盘上，先连成五子的一方获胜
3. 可以横向、纵向或对角线连线
4. 支持双人对战和人机对战

---

### 2. 割草机种花小游戏 (`lawn-mower-game.html`)

一个有趣的模拟经营游戏，驾驶割草机割草并种植美丽的花朵。

#### 功能特性
- 🚜 **可控制割草机**：使用WASD或方向键移动
- 🌱 **随机草地生成**：不同高度的草地
- 🌸 **种花系统**：5种不同颜色的花朵
- 🌱 **完整生长过程**：4个阶段的生长动画
- 📱 **移动端支持**：触摸控制和虚拟方向键
- 🏆 **得分系统**：割草和种花获得分数

#### 游戏玩法
1. 使用方向键控制割草机移动
2. 驾驶割草机割草获得分数
3. 点击种子包切换到种植模式
4. 在割过的草地上种植花朵
5. 观察花朵从种子到绽放的完整生长过程

## 技术栈

- HTML5
- CSS3 (响应式设计 + 动画)
- JavaScript (ES6+)
- 无需外部依赖

## 部署

### 本地运行
直接在浏览器中打开相应的HTML文件即可开始游戏。

### Vercel部署
1. 将代码推送到GitHub仓库
2. 在Vercel中导入GitHub仓库
3. 自动部署完成
