# 网页游戏合集

包含三个有趣的网页游戏，支持桌面端和移动端。

## 🎮 游戏列表

### 1. 五子棋游戏 (`gomoku.html`)

一个现代化的网页五子棋游戏，支持双人对战和人机对战。

#### 功能特性
- 🎮 **双人对战模式**：两个玩家轮流下棋
- 🤖 **人机对战模式**：与智能AI对战
- 🎯 **四个难度等级**：简单、中等、困难、专家
- 📱 **响应式设计**：完全适配手机和平板设备
- 🏆 **获胜检测**：自动检测五子连线
- 🔄 **重新开始**：一键重置游戏

#### 游戏规则
1. 黑棋先行，玩家轮流下棋
2. 在15×15的棋盘上，先连成五子的一方获胜
3. 可以横向、纵向或对角线连线
4. 支持双人对战和人机对战

### 2. 割草机种花小游戏 (`lawn-mower-game.html`)

一个有趣的模拟经营游戏，驾驶割草机割草并种植美丽的花朵。

#### 功能特性
- 🚜 **可控制割草机**：使用WASD或方向键移动
- 🌱 **随机草地生成**：不同高度的草地
- 🌸 **种花系统**：5种不同颜色的花朵
- 🌱 **完整生长过程**：4个阶段的生长动画
- 📱 **移动端支持**：触摸控制和虚拟方向键
- 🏆 **得分系统**：割草和种花获得分数

#### 游戏玩法
1. 使用方向键控制割草机移动
2. 驾驶割草机割草获得分数
3. 点击种子包切换到种植模式
4. 在割过的草地上种植花朵
5. 观察花朵从种子到绽放的完整生长过程

---

### 3. 快乐农场 (`farm-game.html`)

一个完整的农场经营游戏，种植各种作物并收获果实，与小人一起管理农场。

#### 功能特性
- 👨‍🌾 **可控制农民**：使用WASD或方向键控制小人移动
- 🌱 **多种作物**：种植草、玉米、水果三种作物
- 🌽 **完整生长系统**：4阶段生长动画（种子→幼苗→生长→成熟）
- 💰 **经济系统**：金币、商店、购买种子
- 💧 **浇水系统**：加速作物生长
- 📈 **升级系统**：收获作物获得经验升级
- 🛒 **商店功能**：购买不同类型的种子
- 📱 **完美移动端**：触摸控制和虚拟方向键

#### 游戏玩法
1. 控制农民在农场中移动
2. 在商店购买种子（草种子5金币，玉米15金币，水果25金币）
3. 选择种植模式，在空地上种植作物
4. 等待作物成熟或浇水加速生长
5. 收获成熟的作物获得金币和经验
6. 用金币购买更多种子扩大农场
7. 升级获得金币奖励
